# Документация модуля

Окно настроек модуля версии `1.1.2` ожидает следующие PDF-файлы:

- `server-setup-ru.pdf` и `server-setup-en.pdf`;
- `card-set-creation-ru.pdf` и `card-set-creation-en.pdf`;
- `localization-creation-ru.pdf` и `localization-creation-en.pdf`.

До публикации релиза замените этот список готовыми PDF, экспортированными из исходных документов в `.sources`.
