# Карточки Крипты

**Карточки Крипты** - модуль Foundry VTT для работы с игровыми карточками, которые хранятся на отдельном сервере **Kripta Cards Web API Server**.

Версия модуля: **1.1.0**.

Автор: **dmicher abathur kubrow**.

## Требования

- Foundry VTT: `13+`.
- Проверенная совместимость: `14`.
- Запущенный и настроенный **Kripta Cards Web API Server** версии `1.1.0`.

Модуль не является самостоятельным хранилищем карточек. Он работает как интерфейс к серверу.

## Установка

Для установки через Foundry VTT используйте URL манифеста релиза:

```text
https://github.com/dkubrow-dev/kripta-cards/releases/latest/download/module.json
```

Для ручной установки распакуйте архив модуля в папку модулей Foundry VTT так, чтобы `module.json` находился в корне папки `dmicher-kripta-cards`.

## Настройка

После включения модуля в мире Foundry VTT откройте:

```text
Настройки игры -> Настройки модулей -> Карточки Крипты
```

Укажите:

- адрес сервера;
- ID и ключ технического пользователя `Reader`;
- ID и ключ технического пользователя `Writer`;
- язык интерфейса берется из настроек Foundry VTT.

Сервер должен разрешать CORS-запросы с адреса Foundry VTT. Это настраивается на стороне сервера в `appsettings.json`.

## Основные Окна

### Каталог карточек

Показывает все карточки, зарегистрированные на сервере.

Доступно:

- выбор категории;
- поиск карточки внутри категории;
- режимы отображения `Таблица` и `Плитки`;
- вывод карточки в чат;
- открытие подробной информации;
- выдача карточки игроку мастером.

Изображение загружается по пути `ImagePath`, который приходит из JSON карточки. Модуль не проверяет достоверность пути; это ответственность сервера.

### Карточки игрока

Показывает карточки, которые есть у выбранного игрока.

Доступно:

- просмотр карточек в режиме таблицы и плиток;
- описание карточки в обоих режимах;
- использование карточки;
- списание карточки мастером;
- запрос новой карточки.

Описание в плитках обрезается до 250 символов, в таблице - до 500 символов. HTML-разметка закрывается корректно и проходит санитаризацию.

### Получить карточку

Позволяет игроку запросить карточку у мастера.

Режимы:

- случайная карточка;
- карточка на выбор.

В режиме выбора список карточек сортируется по алфавиту на стороне модуля.

### Выдать карточку

Позволяет мастеру выдать карточку игроку без запроса из чата.

Режимы:

- случайная карточка;
- карточка на выбор.

В режиме выбора список карточек также сортируется по алфавиту.

### Управление игроками

Окно мастера для привязки пользователей Foundry VTT к игрокам сервера.

Доступно:

- привязка пользователя Foundry к игроку сервера;
- удаление привязки;
- просмотр карточек выбранного игрока;
- выдача карточки выбранному игроку;
- переход в реестр игроков.

### Реестр игроков

Окно мастера для управления игроками сервера.

Доступно:

- создание игрока;
- изменение игрока;
- удаление игрока;
- двойной клик по строке игрока для редактирования.

## Чат

Модуль публикует в чат сообщения о карточках:

- запрос случайной карточки;
- запрос выбранной карточки;
- подтверждение запроса мастером;
- выдача карточки мастером;
- использование карточки;
- вывод карточки в чат.

Сообщения имеют единый внешний вид: заголовок, подзаголовок, изображение, описание и футер. Название карточки сопровождается названием категории в скобках.

Кнопки подтверждения и отмены запроса центрируются и используют спокойные цветовые акценты.

## Безопасность HTML

Названия и описания карточек могут содержать безопасную HTML-разметку для оформления текста.

Перед выводом в интерфейс модуль пропускает эти поля через HTML-санитайзер:

- разрешенная разметка сохраняется;
- опасные теги и атрибуты удаляются;
- исполняемый код не выводится.

Контент карточек при этом не переводится и остается таким, как он записан в серверном реестре.

## Локализация

Модуль использует стандартную локализацию Foundry VTT через файлы в папке `lang`.

Foundry автоматически выбирает подходящий файл локализации по языку интерфейса Foundry VTT.

В версии `1.1.0` добавлены локализации интерфейса на множество языков, включая русский, английский, упрощенный китайский, испанский, французский, немецкий, японский, корейский и другие.

## Изображения Карточек

Сервер возвращает в JSON карточки поле `ImagePath`. Модуль использует это значение для загрузки изображения:

```text
/api/Cards/getCardImage/{imagePath}
```

Такой формат похож на путь к статическому файлу и позволяет браузеру кэшировать изображения.
