# Карточки Крипты

**Карточки Крипты** — модуль для Foundry VTT, подключающий игровой мир к серверу Kripta Cards.

Модуль позволяет использовать систему одноразовых игровых карточек: мастер выдаёт игрокам особые карточки с уникальными эффектами, а игроки могут просматривать доступные им карточки прямо внутри Foundry VTT.

## Важно

Модуль не работает сам по себе. Для его использования необходим запущенный и настроенный **Kripta Cards Web API Server**.

Сервер отвечает за:

- хранение карточек;
- хранение профилей игроков;
- связь игроков Foundry VTT с серверными профилями;
- выдачу и обновление доступных карточек;
- предоставление изображений и описаний карточек.

## Совместимость

- Foundry VTT: `13+`
- Проверенная версия: `14`

## Настройка

После установки модуля необходимо открыть настройки мира Foundry VTT:

```text
Настройки игры → Настройки игры → Карточки Крипты
```
